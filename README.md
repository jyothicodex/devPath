# 🚀 DevPath

> A clean and interactive developer roadmap website that helps beginners choose a path, follow structured roadmaps, and build real projects.

DevPath is built using **HTML, CSS, and JavaScript**.  
It is designed for students and beginners who want a simple, visual, and practical guide to start their developer journey.

---

## 🌟 Why DevPath?

Many beginners feel confused about:

- What to learn first
- Which developer path to choose
- What projects to build
- How to become job-ready

**DevPath solves this by combining roadmaps, project ideas, cheatsheets, and step-by-step project guidance in one place.**

---

## ✨ Key Highlights

- 🎯 Choose your developer path
- 🧭 Follow structured learning roadmaps
- 💻 Explore beginner to advanced project ideas
- 📚 Access Java, Python, and JavaScript cheatsheets
- 🔍 Filter projects by difficulty level
- 🪟 View project details in interactive modals
- ❓ Learn from FAQ-based guidance
- 📱 Fully responsive design
- 🌙 Modern dark theme UI
